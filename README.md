# Sweet Crumbs — Baked With Love, Served With Joy 🍰

A responsive landing page for a fictional bakery, celebrating the joy of freshly baked treats, homemade goodness, and delightful flavors.

Sweet Crumbs combines soft pastel colors, elegant typography, and delicious bakery-inspired imagery to create a warm and inviting digital experience where visitors can explore freshly baked cakes, pastries, cupcakes, and other sweet delights.

## 🔗 Figma Design

Explore the UI/UX design and visual direction:

[**View Sweet Crumbs on Figma →**](https://www.figma.com/make/MpSBsGfoyx3JMIXzBlmr6R/Sweet-Crumbs-Bakery-Landing-Page?t=PuLdiC9RcPUVfyKA-1)

## ✨ Features

- **Hero Section:** Introduces the bakery with an attractive headline, delicious bakery imagery, and a call-to-action button.
- **Shop by Category:** Helps visitors explore different bakery items such as cakes, cupcakes, pastries, and cookies.
- **Featured Products:** Showcases popular bakery creations through attractive image-based product cards.
- **About Our Bakery:** Highlights the bakery's story, passion for baking, and commitment to quality ingredients.
- **Why Choose Us:** Communicates the benefits of fresh ingredients, homemade recipes, and freshly baked products.
- **Customer Testimonials:** Builds trust through customer reviews and experiences.
- **Newsletter Section:** Encourages visitors to subscribe for updates, special offers, and new bakery collections.
- **Responsive Design:** Includes desktop and mobile layouts for a smooth browsing experience across different screen sizes.
- **Consistent Design System:** Uses cohesive colors, typography, spacing, and reusable interface components.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <https://github.com/Mansi-Patil13/Sweet-Crumbs---Bakery-Landing-Page-.git>
   ```

2. Open the `landing-page` folder.
3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No frontend framework is required for the HTML, CSS, and JavaScript implementation.

## 💡 Design Approach

Sweet Crumbs focuses on **brand storytelling, visual product discovery, and responsive usability**. Elegant headings establish the bakery's personality, soft pastel colors create a warm and delightful atmosphere, and attractive product images help visitors explore the bakery's offerings naturally.

The project explores the process of translating a Figma design into a responsive web interface while maintaining visual consistency across desktop and mobile screens.
